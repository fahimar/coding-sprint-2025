## **🎯 Daily Routine:**

- **সকাল (45 min):** 1-2 problems solve
- **বিকাল/সন্ধ্যা (1 hour):** 1-2 problems solve + previous problems review
- **রাত (15 min):** ৩ লাইনে আজকের শিখা pattern লিখে রাখো

3. **Stuck হলে 15 min পর skip করো**, later এ ফিরে আসবে
